# EasyCloud Website

A beautiful, responsive website built with HTML, CSS, and JavaScript. This website features a modern design with smooth animations, mobile responsiveness, and interactive elements.

## Features

- Responsive design that works on all devices
- Modern and clean UI with smooth animations
- Mobile-friendly navigation
- Contact form with validation
- Smooth scrolling navigation
- Intersection Observer for scroll animations
- Beautiful gradient backgrounds
- Font Awesome icons integration

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (ES6+)
- Font Awesome Icons

## Getting Started

1. Clone this repository or download the files
2. Open `index.php` in your web browser
3. No additional setup required!

## Project Structure

```
├── index.php          # Main HTML file
├── styles.css          # CSS styles
├── script.js           # JavaScript functionality
├── about.php          # About page
├── contact.php        # Contact page
├── blogs/              # Blog articles
├── images/             # Image assets
└── README.md          # Project documentation
```

## Customization

You can customize the website by:

1. Changing colors in `styles.css`
2. Modifying content in `index.php`
3. Adding new features in `script.js`
4. Updating the logo and branding
5. Adding your own images and content
